# Gem Shop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make gems a currency, one per cleared tile, banked at game over and saved in `localStorage`. Add a shop between runs that sells unlocks (perks and items joining the level-up pool) and a small capped KIT (POUCH I/II, SECOND LOOK, EARLY PICK).

**Architecture:** The shop's stock, prices, save cleaning, buying, the locked pool and the start kit are pure functions in `js/upgrades.js`, checked from Node. `js/game.js` handles the rest:
- the run's gem count and banking;
- the `shop` state, with its input and drawing;
- the title and game-over additions;
- SECOND LOOK on the level-up screen and EARLY PICK in `newGame()`.

**Tech Stack:** Plain browser JavaScript (globals via `<script>` tags, must run from `file://`), canvas 2D at 320×272, Node `assert` checks, and headless Chrome via `tools/shot.mjs` (each run uses a fresh profile, so `localStorage` starts empty).

**Spec:** `docs/superpowers/specs/2026-10-16-gem-shop-design.md`

## Global Constraints

- **Runs from `file://` with zero dependencies.** No `fetch()`, no ES modules. New logic goes in the existing IIFEs and is exported on the `api` objects.
- **Pixel-perfect drawing.** Every draw coordinate is an integer. The palette is only `BLACK`/`WHITE`/`RED` plus `GREY`/`DIM`/`DIMRED`.
- **Font.** It has only `0-9 A-Z + - : / ! ? . , ' < > ← → ↑ ↓` and space: no parentheses, no `×`, no `=`. Card names and text lines are at most 14 characters, and a card has at most 4 text lines.
- **Stock and prices (exact):**
  - PERKS shelf: `daredevil` 250, `mirror` 200, `quake` 150, `joker` 200, `scrabbler` 150.
  - ITEMS shelf: `beacon` 60, `wild` 80, `drill` 100.
  - KIT shelf: `pouch` 200, `pouch2` 500 (needs `pouch`, same slot), `secondlook` 300, `earlypick` 600.
  - Total 2,790.
- **Gem multiplier when banking:** MIN 3 ×1, MIN 4 ×1.5, MIN 5 ×2, rounded down. It uses the title-screen `minLen`; PURIST doesn't count.
- **The save.**
  - It is one `localStorage` key, `wordwell.shop`, holding `{ gems, owned }`, read and written only through `store`.
  - `?gems=N` is a sandbox: it starts with `{ gems: N, owned: [] }` and never writes `wordwell.shop`.
  - Runs started with `?level=N` bank 0 (the game-over row reads `NOT BANKED`). `?fast` runs bank normally.
- **The sim baseline must not move.** The five existing `tools/simulate.cjs` rows and the hazards rows must print exactly the baseline in `/private/tmp/claude-501/-Users-mihai-AI-word-tetris/ca403204-15b9-4a86-8eb9-08419263c152/scratchpad/sim-baseline.txt`; ignore the `ms/deal` column. `U.newRun()` with no argument keeps everything unlocked.
- **Checks pass after every task:** `node tools/check-logic.cjs` and `node tools/check-upgrades.cjs`.
- **Commits.** Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work stays on branch `gem-shop`; nothing is pushed.

## Review Focus

1. **Game over with gems still flying to the HUD.** The bank gets every gem, because banking uses the true count (`gemsRun`), not the animated one. Task 2 pins this by banking right after a clear.
2. **A mashed SPACE or ENTER after death.**
   - It can't buy anything: the shop cursor starts on DIVE, and input is ignored for 500 ms.
   - A mashed SPACE can only dive.
   - Task 3 pins this with an immediate SPACE that leaves the state at `shop`.
3. **A corrupt or foreign `wordwell.shop` value** (`"garbage"`, `{gems:"x"}`, unknown ids, `pouch2` without `pouch`). The game loads with the junk cleaned out. Task 1 pins this through `loadSave`, and Task 2 by reloading the page with junk stored.
4. **A long run that exhausts the smaller perk pool.** The cards fill with distinct *unlocked* items, never locked ones. Task 1 pins this.
5. **EARLY PICK taking SINKHOLE on an empty well.** Exactly one piece spawns afterwards and the state is `play`. Task 4 pins this with forced cards.

**Interfaces:**
- Produces, on `U`:
  - `SHOP: Array<{ id, shelf: 'PERKS'|'ITEMS'|'KIT', price: number, slot: string, needs?: string }>`
    - Entries are in shelf order, as in Global Constraints.
    - `slot` is the id of the slot's first tier: `'pouch'` for both `pouch` and `pouch2`; otherwise the entry's own id.
  - `SHELVES: Array<{ name: 'PERKS'|'ITEMS'|'KIT', slots: string[] }>`. The slot ids are
    - PERKS: `['daredevil','mirror','quake','joker','scrabbler']`;
    - ITEMS: `['beacon','wild','drill']`;
    - KIT: `['pouch','secondlook','earlypick']`.
  - `KIT: { [id]: { name, text: (min, run) => string[] } }` for `pouch`, `pouch2`, `secondlook` and `earlypick`, with exact copy:
    - POUCH: `['START EACH RUN','WITH 1 RANDOM','ITEM.']`;
    - POUCH II: `['START EACH RUN','WITH 2 RANDOM','ITEMS.']`;
    - SECOND LOOK: `['ONCE A RUN, V','ON A LEVEL-UP','RE-DEALS THE','CARDS.']`;
    - EARLY PICK: `['A FREE PICK','BEFORE THE','FIRST PIECE.']`.
  - `LOCKED: string[]`: the PERKS and ITEMS shelf ids (8).
  - `shopDef(id) → { name, kind, text }`. `kind` is the perk's family, `'ITEM'` or `'KIT'`; `name` and `text` come from `PERKS`, `ITEMS` or `KIT`.
  - `slotEntry(slot, save) → { entry, owned: boolean }`: the first tier of that slot not in `save.owned`, or, when every tier is owned, the last tier with `owned: true`.
  - `newRun(owned?: string[]) → run`. The run is the old object plus two fields:
    - `locked: string[]`: `[]` when `owned` is undefined, else the `LOCKED` ids not in `owned`;
    - `redeal: false`.
  - `unlockedItems(run) → string[]`: `ITEM_IDS` minus `run.locked`, in `ITEM_IDS` order.
  - `perkPool(run)` also drops ids in `run.locked`. `offerCards` draws its item card and the dry-pool fill from `unlockedItems(run)`.
  - `GEM_MULT = { 3: 1, 4: 1.5, 5: 2 }`, and `gemsBanked(tiles, minLen) → Math.floor(tiles * GEM_MULT[minLen])` (×1 for any MIN not in the table).
  - `emptySave() → { gems: 0, owned: [] }`.
  - `loadSave(raw) → { gems, owned }`:
    - `gems` is `Math.floor(raw.gems)` when it is a finite number ≥ 0, else 0;
    - `owned` is the unique ids of `raw.owned` that are in `SHOP` and whose `needs` (if any) is also kept;
    - anything that isn't an object gives `emptySave()`.
  - `buy(save, id) → { ok: true } | { ok: false, reason: 'unknown'|'owned'|'needs'|'poor' }`. It checks in that order. On success it does `save.gems -= price` and `save.owned.push(id)`.
  - `startKit(run, owned: string[], rng)`:
    - adds 2 random items from `unlockedItems(run)` if `owned` has `pouch2`, else 1 if it has `pouch`, using `addItem` with independent draws;
    - sets `run.redeal = owned.includes('secondlook')`.
- Produces, on `WordWellIcons.card`: `pouch`, `secondlook` and `earlypick`, each 16×16 over `.`/`w`/`r`. The art is the builder's call, in the style of the existing cards: a pouch or sack, two overlapping cards with a circular arrow, and a card with a star or arrow.

  - **Entering and leaving.**

    - `pause` (Esc, P) → `state = 'title'`.

    - Price colour: white if affordable, `DIMRED` if not. It flashes while `deny > 0` for the selected slot.
    - The selected slot gets a red 36×36 frame and the bobbing cursor from `drawCard`.
    - Description column at x 208 to 312:
      - the name (white) and kind (red);
      - for unlocks, `JOINS THE DECK` in grey;
      - a dotted rule;
